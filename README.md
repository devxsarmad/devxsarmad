🩺 MediScribe — AI Clinical Scribe
An AI-powered clinical documentation system designed to turn clinical conversations and patient context into structured medical notes while keeping the doctor in control of the final output.
Rather than treating the LLM as a simple chatbot, MediScribe uses an agentic workflow to gather clinical context, generate documentation, perform safety checks, and require human approval before saving.
Agent Workflow
Clinical Conversation
        ↓
Load Patient Context
        ↓
Load Encounter Context
        ↓
Load Recent Labs
        ↓
Load Prior Notes
        ↓
Generate Clinical Note
        ↓
Safety Review
        ↓
Doctor Review
        ↓
Save Note
What it includes
* Multi-step AI workflow using LangGraph
* Patient and encounter context retrieval
* Recent laboratory result retrieval
* Previous clinical note retrieval
* Structured clinical information extraction
* AI-generated medical documentation
* Safety review before doctor approval
* Human-in-the-loop workflow
* PHI-aware LLM processing
* Agent execution auditing
* Real-time agent progress using Server-Sent Events
* Doctor approval required before final persistence
Stack
TypeScript Node.js LangGraph OpenAI PostgreSQL SSE REST APIs
